# Business Hours & Process Performance Analysis Dashboard
Power BI dashboard for monitoring business process performance, activity success rates, OLA compliance, and ticket processing efficiency.

## Project Overview

This project presents an interactive Power BI dashboard designed to monitor business process performance, activity completion rates, and ticket processing times.

The dashboard provides insights into operational efficiency by analyzing process activities, success rates, OLA performance, and ticket completion metrics. It helps management monitor workflow performance, identify potential delays, and evaluate how efficiently business processes are being handled.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Modeling

## Dashboard Structure

The dashboard consists of three main sections:

### 1. Activity Report

Provides an overview of business process activities and their performance.

Key metrics and features include:

- Total Activity Count
- Successful Activity Count
- Success Rate (%)
- OLA (Operational Level Agreement) monitoring
- Activity trends over time
- Process-level performance comparison
- Color-coded performance indicators to highlight desired, warning, and critical performance levels

### 2. Detailed Activity Report

Provides a detailed view of individual process activities and their workflow information.

Key information includes:

- Process Name
- Department
- Activity ID
- Creator
- Current Status
- Next Status
- OLA Process Time

Interactive filters allow users to explore activities by process name, process category, month, creator, and activity ID.

### 3. Management Report

Provides management-level insights into ticket completion and processing efficiency.

Key metrics and features include:

- Number of Completed Tickets
- Average Ticket Processing Time
- Average Ticket Processing Time by Workday
- Completed Tickets by Month
- Processing Time by Process
- Ticket-level details and processing time

Interactive slicers allow users to analyze performance by process name, process category, month, creator, and ticket ID.

## Key Analytical Objectives

- Monitor business process performance and activity success rates.
- Evaluate process compliance with defined OLA targets.
- Identify processes with lower success rates or potential performance issues.
- Track ticket completion trends over time.
- Analyze average ticket processing time to support operational efficiency.
- Provide detailed process-level information for further investigation.
